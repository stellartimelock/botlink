# Contributing to Bot Link

Thanks for helping.

- Open an issue or pull request at https://github.com/stellartimelock/botlink.
- Run `./gradlew :app:testDebugUnitTest` and `cd companion && python3 -m unittest` before sending a change.
- Never commit keystores, passwords, tokens, or `keystore.properties`. `.gitignore` covers them.
- Contributions are accepted under GPL-3.0-or-later.

Contact: stellartimelock@gmail.com
